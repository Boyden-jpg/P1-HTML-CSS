Onderzoek HTML & CSS

Waarom noem je de eerste HTML-pagina meestal index.html?

Standaard startpagina: Als je domein.nl bezoekt, zoekt de server zelf naar een bestand genaamd index.html om te tonen.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig?

Webontwikkelaars gebruiken de HTML Living Standard. Deze wordt een (Living Standard) genoemd omdat HTML voortdurend wordt bijgewerkt en verbeterd. Er is dus niet een vaste eindversie.

Waarom spreken we niet meer over een specifieke CSS-versie?

CSS bestaat uit verschillende modules. Deze modules worden onafhankelijk van elkaar ontwikkeld en bijgewerkt. Daarom spreken ontwikkelaars meestal gewoon over CSS.

Waarom ziet een website er soms anders uit in verschillende browsers?

Browsers zoals Chrome, Edge en Safari gebruiken verschillende browser engines. Hierdoor kunnen ze bepaalde progameer codes net iets anders weergeven. Ook hebben browsers soms verschillende standaardinstellingen.

Welke drie browsers worden wereldwijd het meest gebruikt?

Volgens StatCounter waren in augustus 2026 de drie meest gebruikte browsers wereldwijd:
1 Google Chrome 69,39%
2 Safari 15,83%
3 Microsoft Edge 5,36%

Bron: StatCounter.
Datum: augustus 2026, geraadpleegd op 17 september 2026.
